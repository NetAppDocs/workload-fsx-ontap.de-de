= Speicher-VM-Einstellungen in NetApp Workload Factory verwalten
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
Die Einstellungen einer Storage-VM in NetApp Workload Factory lassen sich verwalten. Die Konfiguration und Aktualisierung von Active Directory für eine Storage-VM, die Aktualisierung des Storage-VM-Kennworts sowie die Verwaltung von Tags für die Storage-VM sind möglich.



[[configure-and-update-ad-for-a-storage-vm-in-netapp-workload-factory]]
== AD für eine Storage-VM in NetApp Workload Factory konfigurieren und aktualisieren

Konfigurieren und aktualisieren Sie Active Directory für eine Speicher-VM in einem FSx für ONTAP Dateisystem in NetApp Workload Factory.

Die gleichen Schritte gelten für die Konfiguration und Aktualisierung von Active Directory für eine Speicher-VM.

.Schritte
. Melden Sie sich mit einem der link:https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html["Konsolenerfahrungen"^]an.
. Wählen Sie das Menü aus image:workloads-menu-icon.png["Über das Hamburger-Menüsymbol kann man zu Workloads wie Speicher, EDA, KI, Datenbanken, VMware und Administration navigieren."] und wählen Sie dann *Speicher* aus.
. Wählen Sie im Speichermenü *FSx für ONTAP* aus.
. Wählen Sie unter *FSx for ONTAP* das Aktionsmenü des Dateisystems mit der zu aktualisierenden Speicher-VM und wählen Sie dann *Verwalten*.
. Wählen Sie in der Dateisystemübersicht unter „Speicher-VMs“ die Option „Verwalten“.
. Wählen Sie im Bildschirm „Speicher-VMs verwalten“ das Aktionsmenü der Speicher-VM aus, für die Sie Active Directory konfigurieren möchten, und wählen Sie dann *Grundlegende Aktionen* > *AD-Konfiguration verwalten*.
. Geben Sie auf der Seite AD-Konfiguration managen Folgendes an:
+
.. *Active Directory-Domain zu verbinden*: Geben Sie den vollständig qualifizierten Domainnamen (FQDN) Ihres Active Directory ein.
.. *DNS-IP-Adressen*: Geben Sie bis zu drei IP-Adressen durch Kommas getrennt ein.
.. *SMB-Server NetBIOS-Name*: Geben Sie den SMB-Server NetBIOS-Namen des Active Directory-Computerobjekts ein, das für Ihre Speicher-VM erstellt werden soll. Dies ist der Name dieser SVM im Active Directory.
.. *Benutzername*: Geben Sie den Benutzernamen des Dienstkontos in Ihr vorhandenes Active Directory ein.
+
Geben Sie kein Domänenpräfix oder Suffix ein. Für `EXAMPLE\ADMIN`, verwenden `ADMIN`.

.. *Passwort*: Geben Sie das Passwort für das Service-Konto ein.
.. *Organisationseinheit (OU)*: Geben Sie die Organisationseinheit ein.
+
Die Organisationseinheit ist der Distinguished Path Name der Organisationseinheit, der Sie Ihr Dateisystem beitreten möchten.

.. *Delegierte Administratorengruppe*: Geben Sie optional die Gruppe Delegierte Dateisystemadministratoren ein.
+
Die Gruppe delegierte Administratoren ist der Name der Gruppe in Ihrem Active Directory, die Ihr Dateisystem verwalten kann.

+
Wenn Sie Microsoft AD von AWS Managed verwenden, müssen Sie eine Gruppe wie AWS Delegated FSX Administrators, AWS Delegated Administrators oder eine benutzerdefinierte Gruppe mit delegierten Berechtigungen für die Organisationseinheit angeben.

+
Wenn Sie eine Verbindung zu einem selbst verwalteten AD herstellen, verwenden Sie den Namen der Gruppe in Ihrem AD. Die Standardgruppe ist `Domain Admins`.



. Wählen Sie *Anwenden*.




[[manage-storage-vm-tags]]
== Managen Sie Storage-VM-Tags

Tags können Ihnen dabei helfen, Ihre Ressourcen zu kategorisieren.  Sie können in NetApp Workload Factory jederzeit Tags für eine Storage-VM hinzufügen, bearbeiten und entfernen.

.Schritte
. Melden Sie sich mit einem der link:https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html["Konsolenerfahrungen"^]an.
. Wählen Sie das Menü aus image:workloads-menu-icon.png["Über das Hamburger-Menüsymbol kann man zu Workloads wie Speicher, EDA, KI, Datenbanken, VMware und Administration navigieren."] und wählen Sie dann *Speicher* aus.
. Wählen Sie im Speichermenü *FSx für ONTAP* aus.
. Wählen Sie unter *FSx for ONTAP* das Aktionsmenü des Dateisystems mit der zu aktualisierenden Speicher-VM und wählen Sie dann *Verwalten*.
. Wählen Sie in der Dateisystemübersicht unter „Speicher-VMs“ die Option „Verwalten“.
. Wählen Sie im Bildschirm „Speicher-VMs verwalten“ das Aktionsmenü der Speicher-VM aus, deren Tags Sie bearbeiten möchten, und wählen Sie dann *Grundlegende Aktionen* > *Speicher-VM-Tags bearbeiten*.
. Auf der Seite Storage-VM-Tags bearbeiten können Sie Tags hinzufügen, bearbeiten oder entfernen.
+
Auf eine Storage-VM können Sie maximal 50 Tags anwenden.

. Wählen Sie *Anwenden*.




[[reset-the-storage-vm-password-in-netapp-workload-factory]]
== Setzen Sie das Speicher-VM-Passwort in NetApp Workload Factory zurück

Setzen Sie bei Bedarf das Kennwort für eine Speicher-VM in NetApp Workload Factory zurück.

.Schritte
. Melden Sie sich mit einem der link:https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html["Konsolenerfahrungen"^]an.
. Wählen Sie das Menü aus image:workloads-menu-icon.png["Über das Hamburger-Menüsymbol kann man zu Workloads wie Speicher, EDA, KI, Datenbanken, VMware und Administration navigieren."] und wählen Sie dann *Speicher* aus.
. Wählen Sie im Speichermenü *FSx für ONTAP* aus.
. Wählen Sie in *FSx for ONTAP* das Aktionsmenü des Dateisystems mit dem Speicher-VM-Passwort aus, das zurückgesetzt werden soll, und wählen Sie dann *Verwalten*.
. Wählen Sie in der Dateisystemübersicht unter „Speicher-VMs“ die Option „Verwalten“.
. Wählen Sie im Bildschirm „Speicher-VMs verwalten“ das Aktionsmenü der Speicher-VM aus, deren Kennwort Sie zurücksetzen möchten, und wählen Sie dann *Grundlegende Aktionen* > *Kennwort zurücksetzen*.
. Geben Sie im Dialogfeld Kennwort zurücksetzen Folgendes ein:
+
.. *Neues Passwort*: Geben Sie ein neues Passwort für die Speicher-VM ein.
.. *Passwort bestätigen*: Geben Sie das neue Passwort zur Bestätigung erneut ein.
