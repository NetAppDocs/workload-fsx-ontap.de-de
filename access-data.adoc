= Zugriff auf Ihre FSX for ONTAP-Dateisystemdaten
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
Sie können von vor Ort auf Ihre FSX for ONTAP-Dateisysteme zugreifen, indem Sie Volumes für NAS-Clients mounten und iSCSI-LUNs für SAN-Clients mounten.

link:https://docs.aws.amazon.com/fsx/latest/ONTAPGuide/supported-fsx-clients.html["Datenzugriff"^]Die Dokumentation zu Amazon FSx for NetApp ONTAP enthält Informationen darüber, wie auf Daten zugegriffen werden kann.

Sie können den Einhängepunkt für Volumes auch in NetApp Workload Factory abrufen.



[[get-mount-point-for-volumes-in-netapp-workload-factory]]
== Holen Sie sich den Mount-Punkt für Volumes in NetApp Workload Factory

Der Mountpunkt eines Volumes kann verwendet werden, um das Volume als CIFS-Freigabe oder auf einem NFS-Client einzuhängen.

.Schritte
. Melden Sie sich mit einem der link:https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html["Konsolenerfahrungen"^]an.
. Wählen Sie das Menü aus image:workloads-menu-icon.png["Über das Hamburger-Menüsymbol kann man zu Workloads wie Speicher, EDA, KI, Datenbanken, VMware und Administration navigieren."] und wählen Sie dann *Speicher* aus.
. Im Menü „Speicher“ die Option *Volumes explorer* auswählen.
. Wählen Sie das Aktionsmenü für das Volume, dann *Grundlegende Aktionen* und anschließend *Einbindungsbefehl anzeigen*.
. Wählen Sie im Dialogfeld Mount-Befehl *Copy* aus, um den Befehl entweder für den NFS-Mount-Punkt oder die CIFS-Freigabe zu kopieren. Sie geben den kopierten Befehl in Ihrem Terminal ein.
. Wählen Sie *Schließen*.
